# ИНСТРУКЦИЯ ПО СОЗДАНИЮ ЛОГА КОМАНД PLAXIS 2D

## ОБЩИЕ ПРАВИЛА ФОРМАТА КОМАНД

### Формат команд:
```
command [target] [param1 [param2 [...]]]
```

### Основные правила:
1. **Каждая команда в одну строку** — все параметры на одной строке
2. **Координаты точек** — в формате `(x y)` с пробелом между координатами
3. **Параметры свойств** — в формате `"Key" value` где value может быть числом или строкой в кавычках
4. **Имена объектов** — без кавычек, если это идентификатор объекта
5. **Материалы** — имена материалов указываются без кавычек (например: `Песок`, `Стенка`)

## ПОСЛЕДОВАТЕЛЬНОСТЬ ВЫПОЛНЕНИЯ КОМАНД

### 1. ИНИЦИАЛИЗАЦИЯ ПРОЕКТА
```
_initializerectangular SoilContour Xmin Ymin Xmax Ymax
_setproperties "Title" "название" "Company" "" "Comments" "" "UnitForce" "kN" "UnitLength" "m" "UnitTime" "day" "WaterWeight" 10 "ModelType" "Plane strain" "ElementType" "15-Noded"
```

### 2. СОЗДАНИЕ МАТЕРИАЛОВ

#### Материал грунта (Soil):
```
_soilmat "Comments" "" "Metadata" "" "MaterialName" "Название" "Colour" цвет "MaterialNumber" 0 "SoilModel" 2 "DrainageType" 0 "Eref" значение "nu" значение "Cref" значение "phi" значение "psi" значение "gamma" значение "gamma_sat" значение "Rinter" значение ...
```

**Ключевые параметры для Mohr-Coulomb:**
- `"SoilModel" 2` — модель Mohr-Coulomb
- `"Eref"` — модуль упругости (E)
- `"nu"` — коэффициент Пуассона
- `"Cref"` — сцепление (c)
- `"phi"` — угол внутреннего трения (φ)
- `"psi"` — угол дилатансии
- `"gamma"` — удельный вес ненасыщенного (γunsat)
- `"gamma_sat"` — удельный вес насыщенного (γsat)
- `"Rinter"` — коэффициент прочности интерфейса

#### Материал пластины (Plate):
```
_platemat "Comments" "" "Metadata" "" "MaterialName" "Название" "Colour" цвет "EA" значение "EA2" значение "EI" значение "nu" значение "d" значение "w" значение ...
```

**Ключевые параметры:**
- `"EA"` — осевая жесткость
- `"EI"` — изгибная жесткость
- `"nu"` — коэффициент Пуассона
- `"d"` — толщина
- `"w"` — вес на единицу длины

#### Материал анкера (Anchor):
```
_anchormat "Comments" "" "Metadata" "" "MaterialName" "Название" "Colour" цвет "EA" значение "Lspacing" значение ...
```

**Ключевые параметры:**
- `"EA"` — жесткость анкера
- `"Lspacing"` — шаг анкеров

### 3. СОЗДАНИЕ ГЕОМЕТРИИ

#### Скважина и слои грунта:
```
_borehole X
_soillayer номер_скважины
_set Soillayer_номер.Zones[0].Top значение
_set Soillayer_номер.Zones[0].Bottom значение
_set Soillayer_номер.Soil.Material НазваниеМатериала
```

#### Переход к структурам:
```
_gotostructures
```

#### Создание пластины (стенки):
```
_plate (x1 y1) (x2 y2)
_setmaterial (Plate_номер) НазваниеМатериала
```

#### Создание интерфейсов:
```
_posinterface (Line_номер)
_neginterface (Line_номер)
```

#### Создание якоря между узлами:
```
_n2nanchor (x1 y1) (x2 y2)
_setmaterial (NodeToNodeAnchor_номер) НазваниеМатериала
```

#### Создание полигона (прямоугольника грунта):
```
_polygon (x1 y1) (x2 y2) (x3 y3) (x4 y4)
_setmaterial (Soil_номер) НазваниеМатериала
```

#### Создание линии:
```
_line (x1 y1) (x2 y2)
```

#### Удаление объектов:
```
_delete (Object_номер)
```

### 4. НАГРУЗКИ

#### Линейная нагрузка:
```
_lineload (x1 y1) (x2 y2)
_set Line_номер.LineLoad.qy_start значение
_set Line_номер.LineLoad.qy_end значение
```

### 5. СЕТКА И РАСЧЕТ

#### Объединение эквивалентных объектов:
```
_mergeequivalents Geometry
```

#### Переход к сетке:
```
_gotomesh
_mesh размер_элемента
```

#### Переход к фазам:
```
_gotostages
```

#### Создание фазы:
```
_phase НазваниеФазы
_set Model.CurrentPhase НазваниеФазы
```

#### Активация элементов в фазе:
```
_activate (Object_номер) НазваниеФазы
_activate (Object_1 Object_2 Object_3) НазваниеФазы
```

#### Деактивация элементов в фазе:
```
_deactivate (Object_номер) НазваниеФазы
```

#### Выполнение расчета:
```
_calculate
```

#### Просмотр результатов:
```
_view НазваниеФазы
```

## ПРИМЕРЫ ИЗ РЕАЛЬНОГО ЛОГА

```
_soilmat "Comments" "" "Metadata" "" "MaterialName" "Песок" "Colour" 15262369 "MaterialNumber" 0 "SoilModel" 2 "DrainageType" 0 "Eref" 20000 "nu" 0.3 "Cref" 30 "phi" 30 "psi" 0 "gamma" 20 "gamma_sat" 21 "Rinter" 0.67 ...
```

### Создание стенки:
```
_plate (0 6) (0 -20)
_setmaterial (Plate_1) Стенка
_neginterface (Line_1)
_posinterface (Line_1)
```

### Создание нагрузки:
```
_lineload (0 5) (100 5)
_set Line_8.LineLoad.qy_start -10
```

### Создание фазы и активация элементов:
```

_set Model.CurrentPhase Phase_1
_activate (Line_8_1) Phase_1
_activate (Line_8_2) Phase_1
_activate (BoreholePolygon_1_3) Phase_1
```

## ВАЖНЫЕ ЗАМЕЧАНИЯ

1. **Имена материалов** указываются БЕЗ кавычек: `Песок`, `Стенка`, `тяга`
2. **Координаты** всегда в формате `(x y)` с пробелом
3. **Объекты в скобках** при операциях: `(Plate_1)`, `(Line_1)`
4. **Установка свойств через _set**: `_set Object.Property значение`
5. **Переходы между вкладками**: `_gotostructures`, `_gotomesh`, `_gotostages`, `_gotoflow`
6. **Удаление объектов**: `_delete (Object_номер)`
7. **Отмена действий**: `_undo`
8. **Сохранение свойств материала**: `_sps НазваниеМатериала "параметры"`

## ПОРЯДОК РАБОТЫ С ЗАДАНИЕМ

1. Прочитать задание и определить:
   - размеры модели (границы);
   - параметры материалов (грунт, пластины, анкеры);
   - геометрию (стенки, слои, полигоны);
   - нагрузки;
   - фазы расчета.

2. Создать команды в такой последовательности:
   - инициализация проекта;
   - создание материалов;
   - создание геометрии;
   - назначение материалов;
   - создание нагрузок;
   - генерация сетки;
   - создание фаз;
   - выполнение расчета.

3. Проверить формат команд:
   - каждая команда в одну строку;
   - координаты в формате `(x y)`;
   - корректные имена объектов и материалов.
